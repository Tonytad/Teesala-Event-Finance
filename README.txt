Teesala website
===============
Files: index.html (all 3 pages), css/style.css, js/main.js, images/ (your two logos).
Preview: double-click index.html, or run `python3 -m http.server` in this folder.
Pages are switched with #home, #mc and #finance links, so it works on any static host.
Host it free on Netlify, Vercel, GitHub Pages or Cloudflare Pages by uploading this folder.
To edit: replace hello@teesala.com (it appears in a few places in index.html) and edit the text/stats in index.html.
